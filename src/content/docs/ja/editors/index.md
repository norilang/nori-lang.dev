Nori には、`.nori` ファイル向けの豊富なエディター機能を提供する Language Server Protocol（LSP）サーバーが含まれています。エディターサポートを設定すると、コードを書きながらリアルタイムでフィードバックを受け取ることができ、エラーを確認するために Unity に切り替える必要がありません。

## 機能

Nori LSP サーバーは以下の機能を提供します：

- **診断** — 入力から約 200ms 以内に、構文エラーやセマンティックエラーが赤い下線で表示されます
- **オートコンプリート** — `.`（型メンバー）、`:`（型）、`on`（イベント）の入力後に候補が表示されます
- **ホバー情報** — 識別子にカーソルを合わせると、型、関数シグネチャ、extern マッピングが表示されます
- **定義へ移動** — 変数、関数、カスタムイベントの宣言にジャンプできます
- **シグネチャヘルプ** — 関数やメソッド呼び出しの入力中にパラメーターヒントが表示されます
- **ドキュメントアウトライン** — 現在のファイル内のすべての宣言を一覧で確認できます

**VS Code** は、TextMate 文法、スニペット、LSP クライアント設定をバンドルした専用拡張機能により、最も優れたすぐに使える体験を提供します。Rider と Visual Studio は、組み込みの汎用 LSP クライアントサポートを通じて問題なく動作します。

## クイックスタート

最も簡単なセットアップ方法は Unity から行うことです：

1. Unity プロジェクトを開きます
2. **Tools > Nori > Setup Editor...** に移動します
3. お使いのエディターを選択し、ウィザードの手順に従います

手動セットアップについては、各エディターのガイドをご覧ください：

- [VS Code](./vscode/)
- [JetBrains Rider](./rider/)
- [Visual Studio](./visual-studio/)

すべてのエディターで LSP サーバーバイナリが必要です。ビルド手順については [LSP サーバーのビルド](./building-the-lsp/) をご覧ください。

## アーキテクチャ

LSP サーバーは、Language Server Protocol を使用して stdin/stdout 経由でエディターと通信するスタンドアロンの .NET 8 コンソールアプリケーション（`nori-lsp`）です。Unity 内で実行されるのと同じコンパイラーパイプライン（字句解析器、構文解析器、意味解析器）を再利用しているため、エディターと Unity コンソールで診断結果が同一になります。

サーバーは、extern カタログ JSON ファイルを指す `--catalog` フラグをオプションで受け付けます。このカタログには、利用可能なすべての VRChat SDK の型とメソッドが記述されており、より充実したオートコンプリートと型チェックが可能になります。カタログは Unity で **Tools > Nori > Generate Extern Catalog** から生成できます。
