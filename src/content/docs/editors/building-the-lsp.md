All editor integrations require the Nori LSP server binary (`nori-lsp`). This page explains how to build it.

## Build from Unity (recommended)

The easiest way to build the server is from the Unity Editor. The setup wizard builds the binary, generates the extern catalog, and copies both to the publish directory in one step.

1. Open your Unity project
2. Go to **Tools > Nori > Setup Editor...**
3. Click **Build LSP Server**

The wizard automatically:
- Generates the extern catalog from the VRC SDK (if installed)
- Builds a self-contained binary for your platform
- Copies the catalog next to the binary so editors can find it

The resulting binary path is displayed and can be copied to your clipboard.

:::tip
If the VRC SDK is updated after you build, Unity will show a warning in the Console and in the Nori settings panel reminding you to rebuild. Click **Build LSP Server** again to regenerate everything.
:::

## Building from the command line

If you prefer building outside Unity, you'll need the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later.

Verify your installation:

```bash
dotnet --version
# Should print 8.0.x or later
```

The LSP server source is in `tools~/Nori.Lsp/` within the Nori package directory. Navigate to the `tools~` directory and run:

The publish command produces a self-contained, single-file binary that includes the .NET runtime. No additional dependencies are needed on the target machine.

:::note
CLI builds do not auto-generate the extern catalog. You'll need to generate it separately in Unity (see below) and pass it to the server with `--catalog`.
:::

## The extern catalog

The LSP server accepts a `--catalog` flag:

```bash
nori-lsp --catalog /path/to/extern-catalog.json
```

The extern catalog is a JSON file describing all VRChat SDK types, methods, properties, and enums that are available in Udon. Without it, the server uses a built-in catalog with limited API coverage (~50 common externs). With the full catalog, you get complete autocomplete and type checking for the entire VRChat API.

**If you built from Unity**, the catalog is generated and copied next to the binary automatically — no extra steps needed.

### Generating the catalog manually

If you built from the CLI, generate the catalog in Unity:

1. Go to **Tools > Nori > Generate Extern Catalog** (or open **Project Settings > Nori** and click **Generate Catalog from VRC SDK**)
2. The catalog JSON file is saved to `ProjectSettings/NoriCatalog.json`

The catalog is generated by reflecting over the VRChat SDK assemblies at editor time, so it always matches the SDK version in your project. When the VRC SDK is updated, Unity will log a warning reminding you to regenerate the catalog.

### Passing the catalog to your editor

Each editor has its own way of passing the `--catalog` argument to the LSP server:

- **VS Code:** Set the `nori.catalog.path` extension setting
- **Rider:** Add `--catalog /path/to/catalog.json` to the Language Server arguments
- **Visual Studio:** Add to `lspServerArgs` in `.noriconfig`

See the per-editor setup guides for details.
